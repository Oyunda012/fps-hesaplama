# Performans Konsolu AI - Offline PWA

Bu sürüm PWA olarak çalışır.

1. Siteyi ilk kez HTTPS üzerinden internet bağlıyken aç.
2. Uygulamanın sayfalarını ve oyun görsellerini en az bir kez aç.
3. Tarayıcı menüsünden "Ana ekrana ekle / Uygulamayı yükle" seçeneğini kullan.
4. Sonrasında internet olmadan uygulama açılır.
5. FPS hesaplama, sistem profili, arama ve kayıtlı veriler cihaz içinde çalışır.
6. Gerçek AI analizi internet gerektirir.

Not: Tarayıcı güvenlik politikaları nedeniyle servis çalışanı yalnızca HTTPS (localhost hariç) üzerinde çalışır. Netlify HTTPS sağladığı için uygundur.
